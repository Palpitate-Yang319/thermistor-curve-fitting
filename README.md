# 热敏电阻阻值-温度特性拟合：一个机器学习视角

用机器学习里最基础的几个概念（模型容量、训练/测试误差、过拟合、梯度下降）重做一道经典的
曲线拟合题，并重点考察**外推**能力。

## 问题设定

已知热敏电阻的阻值-温度模型（T 为开氏温度）：

```
R(T) = R25 * exp(B * (1/T - 1/T0))
R25 = 22 kΩ,  B = 3100 K,  T0 = 298.15 K
```

在 0–100℃ 上以 2℃ 为步长采集 51 个点，叠加零均值高斯噪声（σ = 0.5 kΩ ≈ 500 Ω），
用 n 阶多项式做最小二乘拟合，考察阶数 n 对拟合效果的影响。

## 关键设计：测试集放在训练区间之外

| 集合 | 温度范围 | 点数 |
|---|---|---|
| 训练集 | 20–80℃ | 31 |
| **测试集** | **0–18℃ 与 82–100℃** | **20** |

测试集刻意取在训练区间的**外侧**，因此检验的是**外推**能力，而不是内插。
随机划分的测试集太容易通过，测不出真实场景（传感器在标定范围外还能不能用）的问题。

## 主要结论

1. **训练 MSE 随阶数单调下降，外推测试 MSE 反而上升。** 两条曲线分叉的位置就是有效模型复杂度的上限——这是过拟合在外推场景下的典型表现。
2. **σ = 0 的消融实验**：训练误差降到数值量级极小，说明有噪时的误差主要来自噪声；但外推误差依然存在，说明残差不是噪声造成的。
3. **根本原因是模型误配（model misspecification），不只是阶数选得不对。** 真实规律是指数型 exp(1/T)，多项式只能局部逼近，在外推区间必然发散。正确的做法是更换模型族（例如对 1/T 做线性回归），而不是单纯降低阶数。
4. **梯度下降**：特征归一化后（x = (t−50)/30），按 Hessian 最大特征值取 α_max = 2/λ_max，实测 α = 0.95α_max 收敛、α = 1.05α_max 发散，与理论一致；初值只影响收敛步数，不影响终点（凸二次问题只有唯一极小值）。
5. 不做特征归一化时，t⁶ 量级达 1e11，设计矩阵条件数极端，梯度下降无法收敛——这是归一化必要性的直接证据。
